# Notes

If you want to build something like this again from scratch, follow this process

- Create an empty project including starter assets
- Create an empty scene
- Create a skylight
- Create sky atmosphere
- Create height fog
- Click on the heigh fog in the scene
- Turn on volumetric fog
- Click on the skylight
- Turn on realtime capture

- Click on selection mode in the top left
- Landscape mode
- Click create

- Back to selection mode
- Get ready to add the water
- Edit -> Plugins
- Enable water and water extras
- Restart the engine
- You should see an error. Scroll to the end of the collision message and hit "add to ini"

- Now we'll actually add the water
- Click the cube+ menu and Place Actors Panel
- Search for water in the Actors Panel
- Drag water body ocean into the scene
- Adjust the water settings until you like the way it looks
- 8-11 min into the video
